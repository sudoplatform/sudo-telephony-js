    Class DefaultSudoTelephonyClient

    Client used to interface with the Sudo Platform telephony service.

    It is recommended to code to this interface, rather than the implementation class (DefaultSudoTelephonyClient), as the implementation class is only meant to be used for initializing an instance of the client.

    createSingletonKeysIfAbsent

    • createSingletonKeysIfAbsent(): Promise<CreateSingletonKeysIfAbsentResult>

      Create the singleton key pair every phone number is sealed to, if this device doesn't have it.

      Requires SudoTelephonyClientConfig.enforceSingletonKeyPair. Call it once the user is signed in, before provisioning: SudoTelephonyClient.provisionPhoneNumber never creates the key, and fails with SingletonKeyPairNotFoundError without it.

      The result says whether the key had to be created. If it was, the device's key material has changed, so back the keys up again with SudoTelephonyClient.exportKeys. If the user already has phone numbers, a new key also means this device doesn't have the one they're sealed to (for example a second device, or one whose keys were removed), so import the user's key backup with SudoTelephonyClient.importKeys instead.

      Returns Promise<CreateSingletonKeysIfAbsentResult>

      Whether the singleton key pair was created, and its ID.

      Throws

      If the client doesn't enforce a singleton key pair.

    deprovisionPhoneNumber

    • deprovisionPhoneNumber(id: string): Promise<PhoneNumber>

      Deprovision one of the caller's phone numbers.

      The unit of the caller's phone number allowance is returned at once and the number is handed back to the telephony provider in the background. Deprovisioning a number that is already released returns it unchanged, so the call is safe to repeat.

      Only a PhoneNumberState.Active or PhoneNumberState.Suspended number can be deprovisioned.

      Unless SudoTelephonyClientConfig.enforceSingletonKeyPair is set, the number's key pair is then removed from the device, so its messages can no longer be unsealed here. The singleton key pair is never removed.

      Parameters

      • id: string

        The identifier of the phone number to deprovision.

      Returns Promise<PhoneNumber>

      The deprovisioned phone number, in PhoneNumberState.Released.

          input: ListPhoneMessagesForConversationIdInput,
      ): Promise<ListPhoneMessagesResult>

      Get the list of phone messages for the specified conversation, with their sealed fields made readable. Defaults to newest first.

      A conversation groups every message between one phone number and one other party; its id is PhoneMessage.conversationId. The service filters by owner rather than rejecting an unknown conversation, so a conversation that does not exist, or belongs to someone else, reads as an empty page.

      A message that cannot be unsealed does not fail the page. The result is then a partial result that returns the message in failed without its sealed fields, alongside an UnsealingFailedError explaining why.

    provisionPhoneNumber

    • provisionPhoneNumber(input: ProvisionPhoneNumberInput): Promise<PhoneNumber>

      Provision one of the phone numbers from a previous search.

      The SDK generates the key pair that seals the number's messages, registers the public key with the service, and keeps the private key in the device key store. Losing that private key makes the number's messages unreadable, so back it up with SudoTelephonyClient.exportKeys.

      By default each number gets a new key pair. If the service refuses the request, that key pair is removed; after any other failure, such as a network error, it is kept, because the number may have been provisioned with it. With SudoTelephonyClientConfig.enforceSingletonKeyPair, every number shares one key pair instead, and it is never removed. That key pair must first be created with SudoTelephonyClient.createSingletonKeysIfAbsent; provisioning never creates it.

      The returned number is in PhoneNumberState.Provisioning; the order completes asynchronously with the telephony provider. Use SudoTelephonyClient.subscribeToPhoneNumbers to learn when it becomes PhoneNumberState.Active or PhoneNumberState.Failed.

      To make the number belong to a Sudo, pass a Sudo ownership proof issued for OWNERSHIP_PROOF_AUDIENCE. Check SudoTelephonyClient.getConfigurationData to find out whether the deployment requires one.

      Parameters

        Parameters used to provision a phone number.

      Returns Promise<PhoneNumber>

      The phone number being provisioned.
