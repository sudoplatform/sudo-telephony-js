    Interface PhoneNumber

    The Sudo Platform SDK representation of a phone number provisioned by the telephony service.

    Provisioning returns the number in PhoneNumberState.Provisioning. It becomes PhoneNumberState.Active or PhoneNumberState.Failed once the order completes with the telephony provider.
