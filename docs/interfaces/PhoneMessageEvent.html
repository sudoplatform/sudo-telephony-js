    Interface PhoneMessageEvent

    The Sudo Platform SDK representation of a notification that one of the caller's phone messages was received, updated or deleted.

    The event carries no message content, only the change and enough identity to act on it. Fetch the message with SudoTelephonyClient.getPhoneMessage to read its text.
