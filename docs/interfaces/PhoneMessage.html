    Interface PhoneMessage

    The Sudo Platform SDK representation of a message sent to or from one of the caller's phone numbers.

    The other party's number and the message text are sealed in transit and unsealed by the SDK with the private key held on this device, so reading a message requires the device that provisioned the number, or one that imported its keys with SudoTelephonyClient.importKeys.

    Carries every property of PartialPhoneMessage and SealedPhoneMessageProps.
